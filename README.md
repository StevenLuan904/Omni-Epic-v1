# Omni-Epic-v1

This repository collects the two codebases used by Omni-Epic:

- [`pepflow/`](pepflow/) — PepFlow and its OpenFold components.
- [`dynamicbind/`](dynamicbind/) — a vendored copy of [DynamicBind](https://github.com/luwei0917/DynamicBind).

Both directories are ordinary source directories in this repository; DynamicBind is not a Git submodule or fork.

## Sources

- PepFlow: https://github.com/luan004/PepFlow
- DynamicBind: https://github.com/luwei0917/DynamicBind
